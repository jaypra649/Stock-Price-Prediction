# Stock Price Prediction using Machine Learning

## Description
This project predicts future stock prices using Linear Regression and historical stock market data.

## Technologies Used
- Python
- Pandas
- Matplotlib
- Scikit-learn
- Yahoo Finance API

## Features
- Downloads stock data
- Visualizes trends
- Predicts future prices
- Uses machine learning

2. Paste the code
3. Run all cells
